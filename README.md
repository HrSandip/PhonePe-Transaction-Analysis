
# 📊 PhonePe Transaction Analysis Dashboard | Power BI

An interactive Power BI dashboard designed to analyze PhonePe transaction data, understand user behavior, track transaction performance, and discover meaningful business insights.

## 📌 Project Overview

Digital payment platforms generate large volumes of transaction data every day. Analyzing this data helps understand customer behavior, transaction trends, payment performance, and service usage.

This project uses Microsoft Power BI to transform PhonePe transaction data into an interactive dashboard with visualizations, key performance indicators (KPIs), and dynamic insights.

The dashboard provides an overview of transaction activity and helps users explore patterns across different time periods, age groups, services, and customers.

## 🎯 Project Objectives

- Analyze transaction trends over time.
- Monitor total transactions and transaction value.
- Understand user activity and customer behavior.
- Compare transaction contributions across age groups.
- Identify services contributing to transaction value.
- Analyze weekday and weekend transaction patterns.
- Present important insights through interactive visualizations.

## 📈 Key Performance Indicators

The dashboard includes the following KPIs:

- **Total Transactions:** Overall number of transactions.
- **Total Transaction Value:** Combined value of transactions.
- **Unique Users:** Number of distinct users.
- **Successful Transaction Rate:** Percentage of successful transactions.
- **Month-over-Month Growth:** Change in transaction performance compared with the previous month.

## 📉 Dashboard Features

### 1. Transaction Analysis
Analyze transaction activity over time and identify monthly trends.

### 2. Age Group Analysis
Understand how transaction activity is distributed across different age groups.

### 3. Service-Wise Transaction Analysis
Compare transaction values across different services and identify major contributors.

### 4. Top 5 Users
Identify the top five users based on transaction value.

### 5. Weekday vs Weekend Analysis
Compare transaction activity during weekdays and weekends.

### 6. Dynamic Insights
Display important business insights based on the selected data and dashboard filters.

### 7. Interactive Filtering
Explore the dashboard using available slicers and filters.

## 🚀 How to Use This Project

1. Clone or download this repository.
2. Install Microsoft Power BI Desktop.
3. Open `PhonePe_Dashboard.pbix`.
4. If prompted, update the dataset source path.
5. Refresh the data if required.
6. Explore the dashboard using the available filters and visualizations.

## 📂 Dataset

The project uses PhonePe transaction data for analyzing transaction trends and customer activity.
